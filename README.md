# 📝 To-Do List App (Redux Toolkit)

A simple and responsive To-Do List application built using **React** and **Redux Toolkit** for state management.

---

## 🚀 Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Persistent state with Redux Toolkit
- Clean and responsive UI

---

## 🛠️ Tech Stack

- **React**
- **Redux Toolkit**
- **JavaScript**
- **CSS**
